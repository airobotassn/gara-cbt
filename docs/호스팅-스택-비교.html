호스팅/스택 4개 안 비교

PHP+카페24 · 현행 Cloudflare+Supabase · Spring Boot+네이버클라우드 · Spring Boot+AWS. 비용·트래픽 한도·기능 손실을 실제 코드베이스 실측치 기준으로 비교한다. 2026-08-04 작성.

결론부터. 4개 중 2번(현행 Cloudflare + Supabase)이 비용·기능 양쪽에서 압도적이다. 정적 트래픽이 무제한 무료라 방문자가 늘어도 비용이 0에서 시작하고, 나머지 3개는 전부 트래픽에 돈을 낸다.

1번(PHP+카페24)은 돈 문제가 아니라 기능 문제로 탈락한다. 카페24 웹호스팅은 MySQL이라 pgvector가 없다 → 메인 검색 레벨추천과 강의 Q&A가 기능 자체로 사라진다. 구글/게스트 로그인도 직접 다시 만들어야 한다.

카페24를 쓰고 싶은 게 목적이라면 PHP로 바꿀 필요가 없다 — 이 앱의 프론트는 이미 순수 정적 빌드라 dist/를 그대로 올리면 된다(§6 하이브리드 안).

06 권고 — 그리고 표에 없는 5번째 안

4개 안을 다 계산해본 뒤의 판단이다.

① 그대로 두는 게 맞다 (안 2). 이 앱은 트래픽의 97%가 정적 파일이고 Cloudflare는 그걸 무제한 공짜로 준다. DAU 1만 명이어도 월 6.3만원인데, 같은 조건에서 카페24는 105만원, NCP는 97만원, AWS는 111만원이다. 16배 차이가 나며, 나머지 3개 안은 전부 돈을 더 내고 기능을 잃거나 공수를 쓴다.
② 그래도 카페24를 써야 한다면 — PHP로 바꾸지 말고 프론트만 올려라 (하이브리드).
프론트는 이미 순수 정적 빌드다(wrangler.jsonc가 하는 일은 ./dist 서빙 + SPA 라우팅이 전부, 워커 스크립트도 SSR도 없다).
· npm run build → dist/ FTP 업로드
· .htaccess 에 SPA 리라이트 (없으면 /guide 새로고침이 404)
· Supabase Auth → Site URL / Redirect URLs 에 카페24 도메인 추가
· CORS는 _shared/cors.ts 가 * 라 손댈 게 없다

백엔드 43개 함수는 Supabase에 그대로 두면 되고, 잃는 기능이 0이며 작업은 반나절이다. 단, earth.mp4 를 먼저 빼야 한다(§3 참고).
③ 어느 안을 고르든 지금 당장 할 일: earth.mp4 21.6MB 처리. 이건 인프라 선택과 무관하게 이득이다. 지금은 Cloudflare가 공짜로 날라주니 안 보일 뿐, 안 1·3·4 어디로 가든 이 파일 하나가 트래픽 비용의 절반 이상을 만든다. webm/AV1 재인코딩으로 3~5MB로 줄이거나, Cloudflare R2(egress 무료)에 두는 두 가지 길이 있다.
④ Spring Boot로 가야 할 이유가 따로 있다면(팀 역량·발주처 요구) — 안 3과 안 4는 규모에 따라 순위가 뒤집힌다.
· DAU 7,000명 아래에서는 AWS(안 4)가 압도적이다. 고정비가 낮고(월 $40) CloudFront 월 1TB가 상시 무료라 DAU 1,000명 기준 NCP 31만원 vs AWS 5.6만원으로 5.5배 차이가 난다. NCP는 무료 구간이 없어 첫 1GB부터 과금된다.
· 그 위로 가면 NCP가 역전한다. NCP 트래픽은 100원/GB(≈$0.071)로 CloudFront의 $0.12/GB보다 싸다. DAU 1만 명에서 NCP 97만원 vs AWS 111만원으로 뒤집히고, 이후 격차는 벌어진다.
· 단, 에셋만 분리하면(§6 ③) 이 역전은 일어나지 않는다 — 트래픽이 1TB 무료 구간을 못 넘어서 AWS가 계속 이긴다.
· 공통으로, 둘 다 pgvector를 지원하므로 DB 스키마의 26개 함수를 그대로 이전할 수 있고 PHP안처럼 기능을 잃지는 않는다. 재작성 대상은 Edge Function 43개(9,014줄)와 인증뿐이다.
계산 가정 — 방문자당 전송량: 전부 자체 호스팅 25MB / 에셋 분리 1MB(gzip 실측 0.45MB + API JSON). 월 30일. 방문자당 함수 호출 40회(페이지 API 20 + 채팅 폴링 진입률 20% 반영). 서버형(안 3·4)은 DAU 1만 명당 인스턴스 1대로 가정. NCP 서버 2vCPU/4GB 160원/시간, Cloud DB 월 12만원, 트래픽 100원/GB로 개산 — NCP·AWS 요금은 구성에 따라 크게 달라지므로 공식 계산기로 재확인할 것. AWS는 EC2 t4g.small $15 + RDS db.t4g.micro $23 기준이며 프리티어 첫 해는 더 저렴하다.
