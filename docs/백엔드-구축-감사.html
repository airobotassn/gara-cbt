프론트 데모에서 실제 서비스로 — 백엔드로 채워야 할 것 전수 점검

시험을 치는 엔진(출제 → 채점 → 결과계산)은 이미 완성돼 있습니다. 비어 있는 건 그 앞뒤로 붙는 장사(접수·결제·자격증)와, 관리자가 무언가를 올리고 관리하는 운영 전체입니다. 같은 레포의 SEMI-CARIS는 관리자 백오피스가 19개 기능으로 완비된 반면, CBT 관리자에는 쓰기 기능이 0개(응시기록 조회 3개가 전부)입니다.

01

큰 그림 — 손대지 말 것 vs 채워야 할 것

먼저 이미 잘 돌아가는 것부터. 여기는 건드리지 말고, 오른쪽을 새로 만드는 게 이번 작업입니다.

완성 이미 실동작 (재사용/유지)

  • 로그인 — 구글·카카오·익명, 로그아웃, 탈퇴(soft-delete)
  • 프로필 — 이름·젬·이미지 업로드 (Storage)
  • 시험 응시·제출·무효 — start-exam · submit-exam + SEB 보안
  • 성적 계산 — get-exam-result (완성, 화면만 잠김)
  • 마이페이지 응시내역 — my-attempts
  • 홈 검색 라우터 — route-query
  • SEMI-CARIS 전체 + 관리자 백오피스 19기능

없음 프론트 껍데기뿐 (신규 구축)

  • CBT 운영 관리 — 일정·공지·FAQ·문항·정책을 못 올림
  • 원서접수 — 폼 제출해도 저장 안 됨
  • 결제·환불 — "결제하기" = 안내 모달만
  • 본인인증 — 실명·생년월일 수집 경로 없음
  • 수험표 — 페이지 자체가 없음
  • 자격증 — 클라 localStorage 목업 (번호·이미지 클라 생성)
  • 합격발표·진위검증·문의·알림 — 전무
