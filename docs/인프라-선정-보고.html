02 카페24를 제외하는 이유 3가지

  • 핵심 기능 2개가 사라집니다. 검색 기반 레벨 추천·강의 Q&A는 AI 검색용 데이터베이스가 필요한데 카페24(MySQL)에는 없습니다. 우회 불가.
  • 방문자가 늘면 사이트가 차단됩니다. 하루 전송량 한도제 — 현 서비스 기준 요금제별 하루 65~1,638명이 상한이고, 넘으면 그날 접속이 막힙니다.
  • 결제 운영이 불가합니다. 서버 감시·장애 알림·기록 보존 수단이 없고, 전면 재개발 6~10주 동안 결제 개발이 전면 중단됩니다.

"국내 업체라 연락된다"는 장점은 B안(네이버클라우드)이 기능 손실 없이 대체합니다.

03 현행 구성을 전부 유지하지 않는 이유

  • 지금까지 월 0원 수준으로 잘 운영됐지만, Cloudflare·Supabase 모두 해외 업체라 전화·한국어 지원이 없습니다(영어 웹 티켓뿐). 결제 기록 장기 보존도 월 84만 원 요금제부터입니다.
  • 그래서 무료인 화면 배포만 계속 맡기고, 결제·인증 서버는 국내 결제사 연동 사례가 가장 많고 담당자 부재 시에도 채용·외주로 이어받기 가장 쉬운 국내 표준 기술(Spring Boot)로 신설합니다.

05 이행 계획 — 서비스 중단 없이

  1. 결제·본인인증 서버 신설2~3주 — 기존 서비스는 그대로. 추가 비용은 서버 1대분부터.
  2. 결제 오픈 + 운영 감시 가동 — 서버 감시·장애 알림·기록 보존 체계 동시 가동.
  3. 기존 기능 순차 이전운영과 병행 — 기능 단위 검증 후 전환, 문제 시 해당 기능만 원복.

06 함께 결정이 필요한 사항 — 해외 응시료

해외 결제(엑심베이) 수수료는 4.4% + 건당 $0.30 고정입니다. 응시료가 $1이면 수수료만 34%를 넘습니다. 해외 응시료 $5 이상 또는 묶음 상품으로의 가격 결정을 결제 연동 전에 요청드립니다.
