# CARIS 자격검정 이용가이드 — 스크린샷 & PPT 제작 프롬프트

수험생(특히 어르신)이 **신청 → 응시 → 자격증 발급**까지 따라 할 수 있는 이용가이드용 자료.
데스크톱(1280px) 화면을 순서대로 촬영했다. 로그인·데이터가 필요한 화면은 가짜 세션+목데이터로 렌더한 것이라 실제와 동일한 레이아웃이지만 값은 예시다.

## 2) Claude에 붙여넣을 PPT 제작 프롬프트

아래 전체를 복사해 Claude(claude.ai)에 붙여넣고, **이 폴더의 이미지 16장을 함께 첨부**하면 된다.

```
CARIS 자격검정(온라인 CBT 시험) "수험생 이용가이드" 발표자료(슬라이드)를 만들어줘.
자기완결형 HTML 파일 1개(아티팩트)로, 16:9 슬라이드이고 좌우 화살표·스페이스바로 넘겨지고
브라우저 인쇄(Ctrl+P)로 PDF 저장이 되게 해줘.

■ 대상과 톤
- 컴퓨터에 익숙하지 않은 어르신도 혼자 따라 할 수 있어야 한다.
- 한 슬라이드에 "한 가지 동작"만. 문장은 짧고 쉬운 말로. 전문용어는 괄호로 풀이
  (예: SEB = "보안 시험 프로그램", CBT = "컴퓨터로 보는 시험").
- 한국어.

■ 글씨·가독성(중요)
- 글씨는 큼직하되 과하지 않게. 1920×1080 슬라이드 기준으로
  큰 제목 48px, 슬라이드 제목 40px, 소제목 30px, 본문 24px, 최소 20px.
- 고대비: 아주 밝은 배경 + 진한 남색/검정 글씨. 흐린 회색 글씨 금지.
- 줄 간격 넉넉히(1.6 이상), 여백 충분히. 글머리표는 2~3개까지만.

■ 각 슬라이드 구성(좌우 2단)
- 왼쪽: 큰 원형 "단계 번호" 배지 + 짧은 제목 + 1~2줄 설명 + (필요시) 작은 팁 한 줄.
- 오른쪽: 해당 화면 스크린샷을 큼직하게.
- 스크린샷 위에서 "눌러야 할 버튼"에 빨간(또는 파란) 동그라미와 화살표를 그리고,
  옆에 짧은 말풍선("여기를 누르세요")을 붙여라. 어디를 누르는지 한눈에 보이게.

■ 색·디자인
- 포인트 색은 파랑(#1D4ED8 계열), 글씨는 남색(#0F172A). 카드 모서리는 둥글게, 그림자는 은은하게.
- 화면 상단에 작은 진행 표시(예: 3 / 15)를 넣어 지금 몇 단계인지 보이게.

■ 슬라이드 순서와 내용(첨부 이미지 파일명 = 그 슬라이드에 쓸 스크린샷)
0. 표지: "CARIS 자격검정 이용가이드 — 신청부터 자격증 발급까지"
1. 목차/전체 흐름 한눈에: 신청 → 준비 → 시험 → 결과 → 자격증 (아이콘 5개 정도로)
2. [01-home.png] 홈에서 파란 「자격검정 응시」 누르기
3. [02-gate.png] 「CARIS 자격검정 응시하기」 누르기(구글 로그인)
4. [03-schedule.png] 응시할 시험 고르고 「접수하기」
5. [04-apply.png] 자격(Pro/Master) 고르고 「결제하기」로 응시료 납부
6. [05-check.png] 시험 전 "보안 시험 프로그램(SEB)" 내려받아 설치
7. [06-prepare-guide.png] 시험 당일: 응시 준비 안내 읽고 「다음」
8. [08-prepare-check.png] 내 컴퓨터 자동 점검 + 모의 문제 한 번 풀어보기
9. [09-prepare-ready.png] 동의 체크 후 「시험 시작」
10. [09b-seb-popup.png] 「SEB로 시험 열기」 팝업 → 보안 브라우저 실행
11. [10-exam-cbt.png] 시험 화면: 보기 클릭 또는 오른쪽 답안지로 답하고, 다 풀면 「제출」
12. [11-complete.png] 제출 완료(결과는 발표일 이후 마이페이지에서)
13. [12-result-pass.png] (발표일 이후) 점수·급수 확인 후 「자격증 발급(PDF)」
14. [14-certificate.png] 「PDF로 저장 / 인쇄」로 자격증 받기
15. [15-mypage.png] 마이페이지에서 응시내역·성적·자격증 확인
16. 마무리: "궁금하면 고객센터로 문의하세요" + 핵심 3줄 요약

각 슬라이드의 설명 문구는 위 내용을 쉬운 말로 다듬어서 넣어줘.
스크린샷 속 예시 값(이름·점수·날짜)은 설명에 그대로 쓰지 말고 일반적인 안내로 바꿔줘.
먼저 슬라이드 1~3장만 만들어 스타일을 보여주고, 내가 확인하면 나머지를 이어서 완성해줘.
```

> 팁: Claude가 이미지를 못 넣으면 "첨부한 이미지를 각 슬라이드에 배치해줘"라고 다시 말하면 된다.
> 실제 .pptx(파워포인트 편집본)가 필요하면 "이 내용을 python-pptx로 .pptx 파일로도 만들어줘"라고 요청.
