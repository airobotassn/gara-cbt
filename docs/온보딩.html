1한 문장 요약

20문항으로 6개 영역(프롬프트·모델/도구·검증·자동화·데이터·윤리)의 AI 활용능력을 측정하고, 롤(LoL) 스타일 누적 티어(아이언~마스터)를 부여하는 웹 서비스.

  • 비로그인(게스트)도 응시 가능 → 총점만 노출
  • 구글 로그인 시 티어 · 6축 레이더 · 오답노트 잠금 해제 (게스트 결과를 그대로 이관)
  • 메인에서 검색어로 레벨 추천 (Gemini 임베딩 코사인, 생성 없는 검색 방식)
  • 라이브: https://gara-home.airobotassn.workers.dev (Cloudflare)

25분 Quick Start (로컬 실행)

전제: Node 18+ (권장 20+), git, 그리고 이미 셋업된 Supabase 프로젝트의 URL/anon key. Supabase 를 처음부터 만든다면 먼저 §3 Supabase 최초 셋업을 1회 수행하세요.
# 1) 클론 & 의존성
git clone <repo-url> ai-level-test
cd ai-level-test
npm install        # 윈도우에서 실행정책에 막히면 npm.cmd install

# 2) 프론트 환경변수 (.env.local 을 루트에 생성)
#    VITE_SUPABASE_URL=https://<ref>.supabase.co
#    VITE_SUPABASE_ANON_KEY=<anon public key>

# 3) 개발 서버
npm run dev        # → http://localhost:5173

자주 쓰는 명령

명령하는 일
npm run devVite 개발 서버 (HMR, localhost:5173)
npm run buildtsc -b && vite build → 타입체크 후 dist/ 번들
npm run lintESLint 전체 검사
npm run preview빌드 결과 미리보기
npm run test:responsivePlaywright 반응형 테스트
윈도우 주의: PowerShell 실행정책에 npm/npx 가 막히면 npm.cmd / npx.cmd 를 쓰세요. (영구 해결: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned)

동작 확인 체크 (셋업이 제대로 됐는지)

  • 비로그인 응시 → 결과창에 총점만 보이고 티어/레이더/해설은 잠김
  • 결과창에서 구글 로그인 → 같은 결과로 잠금 해제 + 유지
  • 브라우저 콘솔에서 supabase.from('test_attempts').select() → 0행 (서버 잠금 정상)

3Supabase 최초 셋업 (1회)

로컬에서 시험이 실제로 돌아가려면 Supabase 백엔드가 있어야 합니다. 처음 1회만 아래를 순서대로 진행하세요. (원본: SETUP.md)

1
프로젝트 생성 — supabase.com → New project (Region Northeast Asia (Seoul) 권장). 생성 후 Project Settings → API 에서 3개를 메모: Project URL, anon public key, service_role key(비밀 — 자동 주입되니 어디에도 붙여넣지 않음).
2
프론트 환경변수 — 루트 .env.local 에 입력: 
VITE_SUPABASE_URL=https://<ref>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon public key>
3
DB 스키마 + 시드 — 대시보드 SQL Editor 에서 ① supabase/schema.sql 전체 붙여넣기 → Run, ② supabase/seed.sql 전체 붙여넣기 → Run(샘플 문제 168개 — 나중에 실제 문항으로 교체).
4
로그인 켜기 — Authentication → Providers 에서 Anonymous Enable(비로그인 응시 필수) + Google Enable. Google 화면의 Callback URL(https://<ref>.supabase.co/auth/v1/callback)을 복사 → Google Cloud Console 에서 OAuth 동의화면(External) 구성 → 웹 애플리케이션 OAuth 클라이언트 ID 생성 → 승인된 리디렉션 URI 에 Callback URL 붙여넣기 → 발급된 Client ID/Secret 을 Supabase Google provider 에 입력 후 Save.
5
URL 설정 — Authentication → URL Configuration: Site URL = http://localhost:5173, Redirect URLs 에 http://localhost:5173/** 추가. (배포 후엔 운영 도메인 https://gara-home.airobotassn.workers.dev 도 Site URL = 그 주소, Redirect URLs 에 .../** 추가 — 도메인 바뀌면 반드시 갱신, 미갱신 시 로그인 후 404)
6
Edge Functions 배포 + Gemini 키 — 함수는 git push 로 안 올라갑니다. CLI 로 배포: 
# CLI 로그인 + 프로젝트 연결
npx.cmd supabase login
npx.cmd supabase link --project-ref <ref>

# 함수 5종 배포
npx.cmd supabase functions deploy start-test
npx.cmd supabase functions deploy submit-test
npx.cmd supabase functions deploy get-result
npx.cmd supabase functions deploy list-attempts
npx.cmd supabase functions deploy recommend-level

# 레벨 추천용 Gemini 키를 함수 시크릿으로 등록 (키: https://aistudio.google.com/apikey)
npx.cmd supabase secrets set GEMINI_API_KEY=<your-key>
자세한 배포 규칙은 §17 배포 파이프라인 참조.
검증: §2 의 동작 확인 체크 3개가 모두 통과하면 셋업 완료입니다.

sequenceDiagram

    participant A as AuthProvider

    U->>A: 응시 시작 (세션 없으면 익명 생성)

    ST-->>U: { attemptId, questions[] }  ⟵ correct_index 미포함
    Note over U: 전체화면 응시 · 이탈감지(§14)
    U->>SU: { attemptId, answers[], violationCount } + JWT
    SU->>DB: TTL 검증 → 채점 → 축별 perf → user_skill EWMA 갱신(applied 1회)
    alt 로그인 유저
        SU-->>U: 전체 결과(티어·6축·해설·deltas)
    else 게스트
        SU-->>U: 잠금 결과(총점만)
    end
    Note over U: 게스트가 나중에 구글 로그인하면
    U->>GR: { attemptId, claimToken }
    GR->>DB: claim_token 일치 시 user_id 이관 + perf 1회 적용
    GR-->>U: 잠금 해제된 전체 결과

🔒 정답 비노출

correct_index 는 출제 응답에 절대 안 실립니다. 채점은 서버에서만.

♻️ applied 멱등

채점·레이팅 적용은 딱 1회. 중복 제출/새로고침 farming 방지.

🎫 claim 이관

게스트 결과를 claim_token 으로 로그인 계정에 1회 이관.

⏳ TTL 120분

ATTEMPT_TTL_MINUTES=120 — 오래된 in_progress 는 서버가 만료.

핵심 수식

// 한 축 성적: 추측 기댓값을 깎고 레벨 천장을 곱한 뒤 실수 페널티 지수
axisPerf(level, ratio) = LEVEL_WEIGHT[level] * clamp((ratio-0.25)/0.75)^1.5

// 누적 갱신: 배치 전이면 perf 그대로, 이후엔 상승 빠르게/하락 천천히
updateAxis(prev, perf, placed) = placed ? prev + k*(perf-prev) : perf   // k = perf>=prev ? 0.25 : 0.1

// 종합: 평균 70% + 최저축 30%
computeOverall = 0.7 * mean(6축) + 0.3 * min(6축)
