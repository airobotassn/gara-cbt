## 1. Supabase — 스키마 적용 (딱 1회)

통합 스키마는 **기존 CBT DB에 레벨테스트 테이블을 "추가만" 하는 멱등 마이그레이션**이다.

**방법 A — CLI (권장, 프로젝트가 linked 돼 있으면):**
```bash
supabase db push
```

**방법 B — 대시보드 SQL 에디터:**
`supabase/migrations/20260701120000_add_leveltest_tables.sql` 파일 내용을 통째로 복사 → CBT 프로젝트 SQL 에디터에 붙여넣고 실행.

> 생성/추가되는 것: `test_questions`·`test_attempts`·`test_answers`·`user_level_skill`·`user_progress`·`question_reports`·`reco_cache`·`reco_shadow_log`, `profiles.is_anonymous`/`deactivated_at` 복구, `user_level_skill.rating`, `global_top`·`purge_deactivated_accounts` RPC, `attempt_status` enum, `vector` 확장. (CBT 테이블·데이터는 안 건드림)

## 2. Supabase — 인증·시크릿 설정

**(a) 익명 로그인 켜기** (게스트 레벨테스트에 필수):
- 대시보드 → Authentication → Providers/Sign In → **Anonymous sign-ins = 활성화**.

**(b) 함수 시크릿:**
```bash
supabase secrets set GEMINI_API_KEY=<제미나이 키>     # 홈 레벨추천 검색창(recommend-level)에 필요
# ROOT_ADMIN 은 기본값 airobotassn@gmail.com — 바꾸려면:
# supabase secrets set ROOT_ADMIN=<관리자 이메일>
```

**(c) 문항 시드** (레벨테스트 문제은행 `test_questions` 가 비어있으면 응시 시 "문제가 없습니다"):
- 실제 레벨테스트 문항을 `test_questions` 에 넣어야 함. (ai-level-test 의 seed 를 `test_questions` 로 옮겨 넣거나, 관리자 문항생성 파이프라인 사용)

## 3. Supabase — Edge Functions 배포 (CLI 전용)

`_shared` 를 쓰는 함수라 **반드시 CLI**로 배포 (대시보드 웹에디터 금지 — `../_shared` 깨짐).

```bash
# 레벨테스트 함수 7종 + 관리자
supabase functions deploy start-test
supabase functions deploy submit-test
supabase functions deploy get-result
supabase functions deploy list-attempts
supabase functions deploy recommend-level
supabase functions deploy leaderboard
supabase functions deploy submit-report
supabase functions deploy admin-test
# (CBT 함수 start-exam·submit-exam·admin 등은 이미 떠 있으면 그대로)
```
> `recommend-level` 은 `_shared` 미사용(단일 파일)이라 대시보드도 가능하지만, 나머지는 CLI 필수.

## 4. 프론트 — .env.local 확인 후 배포

**`.env.local`** 이 **통합 Supabase(CBT 프로젝트)** 를 가리키는지 확인:
```
VITE_SUPABASE_URL=https://lditytpxuuojfznwfnep.supabase.co
VITE_SUPABASE_ANON_KEY=<CBT 프로젝트 anon key>
```

**배포 (Cloudflare 자동):**
```bash
# 브랜치를 master 에 병합 → push → Cloudflare 자동 빌드·배포
git checkout master
git merge feat/merge-leveltest
git push origin master
```
> Cloudflare 는 단일 워커(`gara-cbt`)로 `/` , `/exam/*`, `/test/*`, `/ranking` 전부 서빙(SPA). ai-level-test 워커(`gara-leveltest`)는 그대로 둠(은퇴 보류).
> OAuth 도메인이 바뀌면 Supabase Auth **Site URL / Redirect URLs** 갱신 필요.

## 5. 스모크 테스트 (배포 후 순서대로 눌러보기)

1. 홈 `/` → 검색창에 "나 초보야" → 상위 % 뜨는지 (recommend-level·GEMINI 키 확인)
2. "무료 레벨 진단" 또는 FAB → 레벨테스트 → `/test/select` 진입
3. Lv.1 시작 → 20문항 응시 → 제출 → 결과(게스트는 총점만 + 로그인 유도)
4. 구글 로그인 → 결과 이관(등급·레이더 해제) 확인
5. 레벨테스트에서 🏆 랭킹 → `/ranking` 리더보드
6. 마이페이지 → **학습 대시보드** 탭 (레이더·이력)
7. CARIS 원서접수 흐름(`/exam`) 이 그대로 되는지 (기존 기능 무손상 확인)
8. `/admin` → **CARIS 시험 / 레벨테스트** 탭 전환
